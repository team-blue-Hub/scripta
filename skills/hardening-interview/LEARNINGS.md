## 2026-07-15 · first run · question wording

- **Seen:** 1 run
- **Lesson:** questions written like repo commits confuse the expert. Don't pack file
  paths, last-verified dates, and process words ("re-stamp", "route", PR numbers) into
  the question. Ask about the FACT in plain words ("we tell new joiners the widget runs
  on many brands — is that still right?"), one fact per question. Keep the mechanics
  (what happens to which file) out of the options and in the wrap-up summary instead.
- **Evidence:** The interviewee, mid-interview: "honestly wuestions are confusing" —
  after 7 questions phrased like "engineering/repo-map.md (last verified Jul 6) lists
  internal tooling as ONLY: …". They then voided the whole run: "i hope this is a test for
  the skill right? … the questions are confusing and hard to understand." Answers were
  DISCARDED — a confused click is not a verification. Also consistent with the interviewee's standing
  preference: task lists in plain words, no repo jargon.
- **Status:** promoted to SKILL.md Step 3 immediately (a known-broken prompt shouldn't
  wait for the 2–3-run threshold); CONFIRMED by run 2 (same day): 8 plain-words
  questions, zero confusion, 6 of 8 answered (2 skips, both low-stakes re-stamps, not
  wording complaints) → draft PR opened. Fix works; entry stays as the canonical
  "why Step 3 is written that way".

## 2026-07-15 · run 2 · routing answers may point at the intercom

- **Seen:** 1 run
- **Lesson:** a "someone else knows" answer can name a PLACE, not a person ("there was
  an intercom on this to <person> please find it"). Search the team's ask list
  (intercom issues) mid-interview before recording the answer as routed — the answer or
  the pending route is often already there (here: an open intercom issue, rerouted to another team).
  Turning a bare placeholder into a link to the pending question is a better edit than
  leaving "add URL".
- **Evidence:** The interviewee, run 2, Q2 verbatim: "there was and intercom on this
  to <person> please find it anbd you will get the answer".
- **Status:** new; promote to SKILL.md Step 4 if it recurs.
